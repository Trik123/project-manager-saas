# project-manager-saas

## Goal

Build a collaborative project management app (similar to Trello/Linear) to practice **full-stack development** with:

- Frontend: Next.js + Tailwind + React Query
- Backend: Node.js + Express + Prisma + PostgreSQL
- Infra: Docker Compose (Postgres + Redis), GitHub Actions CI

## Core Features

- Authentication (register, login, JWT cookie)
- Workspaces & memberships
- Projects with columns (kanban)
- Tasks with CRUD, drag & drop, labels, priority
- Comments (realtime later)
- Search & filters
- Notifications (stretch)

## Non-Goals (for MVP)

- Billing / subscriptions
- Integrations (Slack/GitHub)
- Advanced analytics

## Success Definition

MVP lets a user:

1. Register & login
2. Create a workspace
3. Create a project with columns
4. Add & move tasks in a kanban board
